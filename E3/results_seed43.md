# E3 晴空指数跨年实验

本次单种子实验复用 E2-A4 的输入、网络、2014/2015/2016 划分和 30 分钟历史窗口，测试集有 209,341 个共同起报时刻。训练目标为未标准化的 GHI / 晴空 GHI，使用指数空间 MSE，最佳检查点选自验证集第 3 轮。恢复 GHI 时乘目标时刻的物理晴空 GHI，并沿用 E2 的 [0,1600] W/m² 最终 GHI 范围；原始指数未裁至 [0,1]。

| 方法 | +5 RMSE / MAE | +10 RMSE / MAE | +15 RMSE / MAE | +30 RMSE / MAE |
|---|---:|---:|---:|---:|
| Smart Persistence | 76.82 / 28.04 | 87.74 / 35.23 | 93.28 / 39.64 | 102.49 / 47.57 |
| E1 直接预测 | 63.49 / 29.68 | 69.29 / 33.20 | 72.84 / 35.92 | 80.01 / 41.31 |
| E2 加性残差 | 62.69 / 28.78 | 69.22 / 32.71 | 73.02 / 35.03 | 80.26 / 40.21 |
| E3 晴空指数 | 63.40 / 30.02 | 68.89 / 32.57 | 72.31 / 35.52 | 78.98 / 40.25 |

单位 W/m²。E3 的整体 RMSE 在 +5 分钟高于 E2，在其余三个提前量低于 E2；这是一组单种子探索结果，不能推断统计显著性。指数空间 MSE 在 GHI 空间相当于对平方误差按晴空 GHI 的平方倒数加权，因此目标参数化与损失隐含权重同时改变，不能将差异完全归因于输出形式。

测试目标晴空 GHI 最小 86.69 W/m²，训练和验证分别最小 86.61 和 86.52 W/m²，均大于零；未增加阈值或更改共同样本。测试预测指数大于 1 的数量分别为 110459、118770、112550、118018，确认没有裁剪至 1。独立检查核实全部测试起报时间、标签及晴空值与共享数据一致，重建值等于裁剪后的指数乘晴空值，且各提前量 RMSE 可复算。图像归档修改时间是否准确反映拍摄或实时可用时刻仍有不确定性。
